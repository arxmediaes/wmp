Conectar IA y datos.

Las funciones locales ya están disponibles. Añade tus workflows de n8n para conectar el asistente y sincronizar los datos con Excel.

Recibe proyecto, mensaje e historial. Debe devolver un JSON con el campo «reply». El modelo y la clave de OpenRouter se configuran en n8n.

Recibe proyecto, acción y datos. Para cargar, devuelve «data». Para guardar, devuelve «ok»: true. Puedes conectar Excel desde ese workflow.

Formato para el workflow
IA → {project, message, history}
Respuesta → {reply: "Texto de respuesta"}

Datos → {project, action: "load" | "save", data}
Respuesta → {data: {...}} o {ok: true}

Token opcional: Authorization: Bearer ...

Los webhooks deben permitir solicitudes desde este sitio. Los endpoints se guardan en el navegador; el token no se guarda en disco.
